# V18 Features

## Smart Reports
- Management KPI summary and financial health score
- Period-over-period insights
- Income/expense trend line chart
- Profit waterfall
- Cash-flow Sankey
- Expense composition donut
- Receivables aging
- Budget variance
- Tax analysis
- Inventory analysis
- Click-to-drill-down into related records
- Saved report views
- XLSX / PDF / CSV exports preserved

## UI themes
- Warm Red / Amber
- Sunrise Yellow / Orange
- Professional Blue
- Modern Purple
- Balanced Light
- Dark Mode

Theme is stored in application state and can be changed from Settings or the top-bar palette shortcut.
