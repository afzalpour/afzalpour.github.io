# RC1.2-C.2 — Thermal Receipt OCR Gate

این Gate ادامه RC1.2-C است و به‌دلیل کیفیت ناکافی OCR روی رسید حرارتی واقعی اضافه شده است.

## مشکل مشاهده‌شده

روی یک رسید واقعی پرداخت الکترونیک، متن OCR قبلی بخش بزرگی از ساختار سند را از دست می‌داد و نویز RTL/Bidi تولید می‌کرد.

ویژگی‌های نمونه مرجع:
- رسید حرارتی چروک‌خورده با نور/پس‌زمینه ناهموار.
- متن فارسی RTL.
- نوارهای تیره با متن سفید.
- ارقام متعدد کارت/پایانه/پیگیری.
- نوار مبلغ مستقل در پایین سند.
- مبلغ نمونه مرجع: `1,000,000 ریال` که Canonical Toman آن `100,000 تومان` است.

## Patch C.2

برای `receipt` و `bank_slip` تصویری:
1. EXIF/orientation-aware decode.
2. Grayscale + percentile contrast.
3. Local background flattening برای سایه و چروک کاغذ.
4. Otsu binary pass.
5. Full receipt block OCR.
6. Sparse text/number OCR.
7. OCR مستقل ناحیه میانی برای تاریخ/پایانه/پیگیری.
8. تشخیص خودکار dark amount band در نیمه پایین.
9. Invert نوار تیره و OCR مستقل مبلغ.
10. حذف Bidi control characters و normalize حروف فارسی.
11. عدم concatenate کورکورانه خروجی چند Pass؛ فقط main text + خطوط مهم ناحیه‌ای.
12. PDF و اسناد تصویری غیر receipt همچنان از pipeline v2 استفاده می‌کنند.

## Acceptance

### C2-1 Persistence
- سند پس از OCR در لیست باقی بماند.
- وضعیت `استخراج شده` باشد.
- اصل فایل قابل مشاهده باشد.
- هیچ Posted journal خودکار ساخته نشود.

### C2-2 Raw OCR quality
روی نمونه رسید مشابه:
- خروجی نباید عمدتاً نویز/حروف شکسته باشد.
- چند برچسب کلیدی سند باید قابل تشخیص باشند؛ مانند:
  - رسید / خرید
  - تاریخ / زمان
  - پایانه / کارتخوان
  - بانک
  - پیگیری / مرجع
  - عملیات موفق
  - مبلغ / ریال

لازم نیست تمام متن لوگو/شرکت بالای رسید دقیق استخراج شود؛ تمرکز روی داده عملیاتی و مالی است.

### C2-3 Amount
برای نمونه مرجع `1,000,000 ریال`:
- extraction باید amount را از نوار مبلغ بگیرد، نه شماره کارت/پیگیری.
- Canonical value باید `100000` تومان باشد.
- اگر UI روی ریال است، نمایش می‌تواند `1,000,000 ریال` باشد.

### C2-4 Date
- اگر تاریخ روی رسید واضح است، باید یک تاریخ معتبر Jalali/Gregorian استخراج شود.
- شماره کارت یا reference number نباید به‌عنوان تاریخ پذیرفته شود.

### C2-5 Human review
- Confidence پایین باید همچنان قابل بازبینی باشد.
- OCR مستقیم Posting نمی‌کند.
