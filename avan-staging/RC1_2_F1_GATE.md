# Gate RC1.2-F.1 — Complete Mobile Navigation

هدف این Gate رفع Regression ناوبری موبایل پس از PASS شدن RC1.2-F است.

## Scope
- Bottom Nav موبایل پنج جایگاه باقی می‌ماند.
- گزینه «بیشتر» یک Sheet موبایلی باز می‌کند.
- مسیرهای پنهان موبایل از طریق همان Navigation معتبر موجود در Sidebar باز می‌شوند.
- هیچ تغییر مالی، Ledger، RLS، RPC یا دیتابیسی در این Patch وجود ندارد.

## Live Gate — iPhone / Mobile Web
1. Hard Refresh انجام بده.
2. Bottom Nav باید شامل این پنج گزینه باشد:
   - خانه
   - حساب‌ها
   - ثبت
   - گزارش
   - بیشتر
3. «بیشتر» را بزن؛ Sheet «بخش‌های بیشتر» باید پایدار و بدون پرش باز شود.
4. از داخل Sheet هر پنج مسیر را جداگانه تست کن:
   - فاکتورها
   - اسناد حسابداری
   - اسناد هوشمند
   - طرف‌حساب‌ها
   - تنظیمات
5. در «طرف‌حساب‌ها» لیست باید دیده شود و افزودن/ویرایش موجود مثل قبل کار کند.
6. در «اسناد حسابداری» اسناد موجود باید دیده شوند و مشاهده/ایجاد سند دستی مثل قبل در دسترس باشد.
7. فاکتورها و اسناد هوشمند باید از موبایل مستقیم قابل دسترسی باشند.
8. وقتی یکی از صفحات داخل «بیشتر» فعال است، خود گزینه «بیشتر» در Bottom Nav حالت Active داشته باشد.
9. Sheet با ضربه روی × یا فضای تیره بیرون بسته شود. در مرورگر دارای کیبورد Escape، Escape نیز باید آن را ببندد.
10. Sheet و Bottom Nav نباید با Home Indicator / Safe Area آیفون برخورد کنند.
11. نسخه دسکتاپ باید Sidebar قبلی را بدون تغییر نشان دهد.

## Expected result
همه مسیرهای اصلی برنامه روی موبایل قابل دسترسی هستند، بدون شلوغ شدن Bottom Nav و بدون Regression در نسخه دسکتاپ.
