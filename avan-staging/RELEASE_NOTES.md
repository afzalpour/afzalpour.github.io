# Avan Core 1.0 RC1

Release Candidate for the accounting core only. No OCR/AI/voice/inventory/invoicing features are added in this release.

Core scope:
- Supabase Auth + Workspace + RLS
- Chart of accounts (کل / معین / تفصیلی)
- Opening balance
- Receipt / payment / transfer
- Manual Draft → Posted → Reversed lifecycle
- Posted immutability and safe reversal
- Fiscal-period lock
- Parties
- Journal, trial balance, account statement, P&L, balance sheet, cash/bank reports
- Core integrity checks
- Mobile bottom navigation and manual journal access

RC1 is staging-only until the two-user RLS live test passes.
