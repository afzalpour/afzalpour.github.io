# Gate RC1.3-B — Company / Operational Settings Completion

هدف این Gate تکمیل مشخصات شرکت و تنظیمات مشترک چاپ است، بدون تغییر منطق مالی، Ledger یا قواعد مالیاتی متغیر.

## Scope
- همان Source of Truth قبلی `workspace_print_profiles` حفظ می‌شود.
- نوع شخصیت: حقیقی / حقوقی / سایر.
- استان و شهر.
- متن ثابت اختیاری پایین فاکتور.
- Header چاپ از نوع شخصیت و موقعیت شرکت استفاده می‌کند.
- Footer فقط در چاپ جزئیات فاکتور نمایش داده می‌شود.
- نرخ مالیات/VAT و قواعد سامانه مودیان در این مرحله Hard-code نمی‌شوند و مطابق ADR-0007 برای ماژول Tax Versioned/Configurable باقی می‌مانند.
- Owner/Manager ویرایش می‌کنند؛ اعضای Workspace فقط خروجی مجاز را می‌بینند.
- بدون تغییر `app.js`، Ledger، Journal lifecycle، Invoice posting یا RLS مالی.

## Live Gate
1. Hard Refresh انجام بده.
2. وارد `تنظیمات` شو.
3. کارت باید با عنوان `مشخصات شرکت و چاپ` پایدار باشد و چشمک نزند.
4. فیلدهای جدید باید وجود داشته باشند:
   - نوع شخصیت
   - استان
   - شهر
   - متن ثابت پایین فاکتور
5. نوع شخصیت را انتخاب کن، استان/شهر و یک متن کوتاه برای پایین فاکتور وارد کن و ذخیره بزن.
6. از تنظیمات خارج شو و دوباره برگرد؛ اطلاعات باید از Cloud باقی مانده باشد.
7. یک فاکتور موجود را باز کن و `چاپ / ذخیره PDF` را بزن:
   - نوع شخصیت در Header رسمی دیده شود.
   - استان/شهر همراه آدرس شرکت دیده شود.
   - متن ثابت پایین فاکتور در انتهای چاپ دیده شود.
8. یک سند حسابداری را چاپ کن؛ متن ثابت فاکتور نباید در سند حسابداری نمایش داده شود.
9. یک گزارش را چاپ کن؛ متن ثابت فاکتور نباید در گزارش نمایش داده شود.
10. Regression: لوگو و اطلاعات قبلی شرکت، اعداد فارسی چاپ و وسط‌چین بودن جدول فاکتور/سند حفظ شده باشند.
11. Regression مالی: ثبت/مشاهده فاکتور، سند و گزارش عادی بدون تغییر کار کند.
