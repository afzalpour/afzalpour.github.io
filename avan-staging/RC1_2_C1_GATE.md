# RC1.2-C.1 — Smart Document return-to-page regression

هدف: پس از پایان OCR، کاربر از صفحه اسناد هوشمند خارج نشود و سند استخراج‌شده گم‌شده به نظر نرسد.

## Gate
1. Hard Refresh.
2. اسناد هوشمند → آپلود یک JPG/PNG/PDF.
3. «استخراج هوشمند» را بزنید.
4. پس از پایان OCR، برنامه می‌تواند برای تازه‌سازی Context یک Reload کنترل‌شده انجام دهد، اما باید خودکار دوباره به «اسناد هوشمند» برگردد.
5. همان سند باید در لیست با وضعیت «استخراج شده» باقی مانده باشد.
6. دکمه «مشاهده» باید اصل فایل را باز کند.
7. دکمه «بازبینی» باید داده استخراج‌شده را نشان دهد.
8. هیچ سند Posted خودکار ساخته نشود.

PASS phrase: `Gate RC1.2-C.1 پاس شد`
