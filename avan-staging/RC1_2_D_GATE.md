# RC1.2-D — Print & Export Center Gate

## Scope
یک Print/Export engine مشترک برای گزارش‌ها، فاکتورها، اسناد حسابداری و اصل فایل اسناد هوشمند.

## D1 — Reports Print / PDF
1. Staging را Hard Refresh کنید.
2. «گزارش‌ها» را باز کنید.
3. Toolbar «خروجی» باید شامل «چاپ / ذخیره PDF» و «خروجی CSV» باشد.
4. یک گزارش مثل تراز آزمایشی یا دفتر روزنامه را باز کنید.
5. «چاپ / ذخیره PDF» را بزنید.
6. Preview باید RTL، فونت فارسی، جدول کامل و بدون دکمه‌های UI باشد.
7. در Print dialog گزینه Save as PDF / ذخیره PDF باید قابل استفاده باشد.

## D2 — Reports CSV
1. روی «خروجی CSV» بزنید.
2. فایل CSV باید دانلود شود.
3. فایل را در Excel/Numbers باز کنید.
4. حروف فارسی و اعداد نباید خراب شوند.
5. ستون‌های جدول گزارش باید قابل تحلیل باشند.
6. برای گزارش‌های KPI مثل سود و زیان/ترازنامه، شاخص و مقدار باید خروجی داده شوند.

## D3 — Invoice detail Print / PDF
1. «فاکتورها» را باز کنید.
2. یک فاکتور را «مشاهده» کنید.
3. در پنجره جزئیات دکمه «چاپ / ذخیره PDF» باید وجود داشته باشد.
4. خروجی باید عنوان، تاریخ/طرف‌حساب، جدول ردیف‌ها و جمع فاکتور را داشته باشد.
5. دکمه‌های UI نباید داخل نسخه چاپی دیده شوند.

## D4 — Journal detail Print / PDF
1. «اسناد حسابداری» را باز کنید.
2. یک سند را «مشاهده» کنید.
3. دکمه «چاپ / ذخیره PDF» باید وجود داشته باشد.
4. عنوان سند، تاریخ/شرح، حساب‌ها، بدهکار و بستانکار باید چاپ شوند.
5. جدول در A4 خوانا باشد.

## D5 — List Print
- در صفحه فاکتورها و اسناد حسابداری، «چاپ فهرست / PDF» باید فهرست جاری را بدون Action buttonها چاپ کند.

## D6 — Smart Document original
1. «اسناد هوشمند» → «مشاهده اصل سند».
2. Viewer باید «دانلود اصل فایل» و «چاپ اصل سند» داشته باشد.
3. تصویر باید در چاپ بدون کنترل‌های Viewer چاپ شود.
4. PDF با «چاپ اصل سند» در تب اصل فایل باز شود تا Print/Save PDF مرورگر استفاده شود.
5. «دانلود اصل فایل» باید فایل اصلی را با نام فایل دانلود کند.

## D7 — Mobile / iPhone smoke
- Toolbar خروجی نباید از عرض صفحه بیرون بزند.
- دکمه‌های چاپ/دانلود Viewer باید قابل لمس باشند.
- اگر Safari پنجره چاپ را Block کرد، پیام راهنما نمایش داده شود.

## D8 — Financial regression
- هیچ داده‌ای با Print/Export تغییر نکند.
- Ledger، Journal lifecycle، RLS و Canonical Toman دست‌نخورده باشند.
- Print/Export صرفاً read/export باشد.
